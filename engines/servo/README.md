# Servo spike removed

Kakangkung’s independent page engine is **Ladybird**, not Servo.

See [`../ladybird/`](../ladybird/) and [`../../docs/LADYBIRD.md`](../../docs/LADYBIRD.md).
WebView2 / Chromium are also removed as page engines — the chrome is native Direct2D and
pages are rendered by Ladybird (LibWeb).
